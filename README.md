# DevProfile — GitHub Developer Profile Analyzer

DevProfile is a web application that lets users explore GitHub profiles and analyze public repository data through a simple, minimal interface.

## Features

- Search GitHub users by username
- View public profile information
- Explore repositories and their details
- Sort repositories by stars, forks, or recent updates
- View programming language insights
- See total stars across public repositories
- Handle invalid usernames and API errors

## Tech Stack

- **Frontend:** React, JavaScript, CSS
- **Build Tool:** Vite
- **API:** GitHub REST API

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/niyati273/Devprofile.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Devprofile
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## API

DevProfile uses the GitHub REST API to retrieve publicly available profile and repository information.
